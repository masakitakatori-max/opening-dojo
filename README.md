# Opening Dojo — 型 × 線 で覚えるオープニング道場

chess.com 風の UI で、序盤の「型」を一手ごとに学ぶ個人練習アプリ。

```bash
npm install       # postinstall で Stockfish (WASM) を public/engine にコピー
npm run dev       # http://localhost:5173
npm run dev:lan   # 同じ Wi-Fi のスマホからも開けるようにする（http://<この PC の IP>:5173）
```

## 公開
`main` に push すると、GitHub Actions（`.github/workflows/deploy.yml`）がビルドして GitHub Pages に公開する。
公開先の URL はサブフォルダ（`/<リポジトリ名>/`）になるので、`public/` のファイルは `src/lib/asset.ts` の `BASE` を通して参照する。
スマホ（iPhone 14 Pro の幅）に対応。Safari の「ホーム画面に追加」で全画面のアプリとして開ける。対局・診断などのデータは端末ごとのブラウザ内に保存され、端末間では共有されない。

## モード
- **今日**：期限の来た復習（自分のミス・狙いドリル・相手の狙い・型ドリル）と、自分の対局で一番多いミスの種類から、今日やることを並べる。連続日数と直近 14 日の量。データの書き出し／読み込みとオフライン保存もここ。
- **振り返り**：取り込んだ自分の対局（直近 150 局の棋譜）をエンジン（別ワーカーの Stockfish、深さ 11）で分析。悪手・ブランダーの局面が「本当はどう指すべきだったか」の問題になり（エンジンが同等と判定すれば別の手も正解）、間隔反復で再出題。
  ミスは種類（詰みの見逃し／詰み筋の見落とし／駒のタダ渡し／相手の戦術の見落とし／自分の戦術の見逃し／方針のミス）と局面（序盤・中盤・終盤）で数え、その種類を鍛えるドリルに直接つなぐ。対局はミス付きで再生できる。
- **探索**：自由に指す。一手ごとに型の名前（ECO）、その手の狙い、「型の線」（ここまでの流れ＋この先の主線）が出る。
  次の候補手は指される割合に応じて盤上のマスが色分けされる（濃いオレンジ＝主線）。定跡を外れると Stockfish の推奨手が青で出る。
- **ドリル**：コース（ルイ・ロペス、ナイドルフ、KID、フィッシャー／カスパロフ／カールセン／カパブランカ／クラムニク／タリの型など）を選び、
  相手のランダムな定跡応手に型どおり応じる。間違えた手順ほど早く再出題される（間隔反復、進捗は localStorage）。
- **図鑑**：名前のついた手・戦術・陣形・詰みの型・定跡を 1 ページに集約。詳しい解説（`src/data/trophyNotes.ts`）、そこに至る手順のリプレイ、指して確かめる盤、獲得したトロフィー。検索と GM での絞り込み。

## 狙いドリル
狙い（フォーク、ピン、そらし、バックランク・メイトなど 21 種類）を固定し、毎回違う局面で解く。難しさは 4 段階、各 50 問。
間違えた問題ほど早く再出題。「ミックス」は狙いを伏せて全種類から出題する。
- 問題は Lichess puzzle database（CC0）から `node scripts/build-aims.ts` で `public/aims.json` に選び出したもの（合計 4,200 問、0.4MB）。
- **攻める／守る**：「守る」は同じ問題をやられる側から見る。①自分の一手のあと、相手の狙い（次の一手）を相手の駒で指して当てる → ②一手戻って、それを防ぐ手を指す（エンジンが判定）。
- **🧠 読み切りモード**：盤は最初の局面のまま動かさず、相手の応手も含めた手順を最後まで入力してまとめて答え合わせ。
- **型から選ぶ**：型ドリルの各コースの定跡から実戦で生まれた戦術（Lichess の OpeningTags、自分がその型を持つ側、各 48 問）。`node scripts/build-openings.ts` で `public/openings.json`。型ドリルの画面からも直接開ける。

## 局面練習
好きな局面を再現し（盤上で駒を配置／FEN・棋譜を貼り付け／探索モードの「🥊 この局面を練習」）、エンジン相手に何度でも指し直す。
一手ごとに判定と理由が出て、開始時からの形勢の変化が見える。局面は名前と「今回の狙い」を付けて保存できる。相手の強さは 3 段階。
対局時計（3+2／5+3／10+5／15+10、最初の一手から動き、時間切れは負け）。分身・セルフ対局でも使える。

## タイプ診断
自分の対局（chess.com / Lichess のユーザー名、または棋譜の貼り付け）から、指し手の偏りを数値にして「どの GM に近いか」と「強み・弱み」を出す。
- 対局は 1 局ずつブラウザに貯め、更新のたびに新しい対局だけを足す（同じ対局は二重に数えない）。診断は直近 300 局で出すので、結果は少しずつ動く。ページを開くと自動で新着を確認する。
- 軸は「総合 5 軸」＋詳細 19 軸（攻め方・局面の好み・駒の使い方・試合運び・序盤）。前回の更新からの変化と、直近 30 局の傾向も表示する。
- 推定レート（`src/lib/rating.ts`）：対局に記録された自分と相手のレートから、持ち時間の種類ごとに現在のレートとパフォーマンス（直近 50 局）を出す。狙いドリルの初見の正誤からは「戦術の推定レート」を出す。
- 物差しは `src/lib/style.ts`。エンジンは使わず、チェックの頻度、相手キングへの圧力、クイーンの使い方、駒交換の速さ、エンドゲーム率などを測る。
- GM 側の数値は `node scripts/build-styles.ts` で `public/ghosts` から作り、`src/data/gmStyles.ts` に書き出す（各 GM の対局を半分に分けた検証つき）。

## 過去の自分と対局（分身）
タイプ診断で貯めた自分の対局から作る対戦相手。タイプ診断の「🪞 過去の自分と対局する」、または局面練習の相手で「🪞 過去の自分」を選ぶ。
- 序盤（自分の対局に出た局面、12 手目まで）：実際に指した手を、指した割合どおりに指す。
- それ以降：エンジンの候補から、自分のクセ（よく動かす駒、チェックの頻度、囲う手数、駒交換の好みなど）に合う手を選ぶ。
- ミス：序盤・中盤・終盤ごとに、自分が駒を損する頻度どおりに駒を取られる手を指す。理由は次の一手を指したあとに表示。
- 指し手の傾向の再現であって、思考の再現ではない（`src/lib/clone.ts`）。

## セルフ対局
白も黒も自分で指すモード（左メニュー「セルフ対局」）。探索モードと同じ盤で、補助が全部使える：有力マスの着色と %、矢印、型の名前と線、候補手、エンジンと評価バー、駒を持ったときの採点、ブランダー警告、GM ゴースト、一手ごとの判定。
- 盤の下の「補助：ON/OFF」でまとめて切り替え、ON のときは個別にも切り替えられる。OFF の間も採点は裏で続くので、ON に戻すと全部の手の判定が出る（振り返り）。
- 盤は白側から固定（⇅ で反転）。対局は探索モードとは別に保存される。芸術点は補助 OFF の間だけ入る。
- 局面練習の相手で「👥 セルフ」を選ぶと、好きな局面からも両方指せる（こちらの補助は判定・形勢・直前の手の狙い・危険な駒）。

## 再生する型（モジュール）
探索とセルフ対局の自動再生には、名前のついた定跡を 1 つ「再生する型」として付け外しできる。付けると、その型に入るまでの手順を再生して止まり、そこから自分で指せる。付けないと、いちばん多く指される手（主線）をたどる。

## トロフィー（芸術点）
局面練習とセルフ対局で、名前のついた手・陣形・詰みの型・定跡を**補助なしで**指すと「芸術点」が入る（補助 ON の間は参考表示のみ）。同じものは 1 局・1 色につき 1 回。
- 例：1.e4 +1、シシリアン +3、キャスリング +2、ピン +2、フォーク +3、バックランク・メイト +15、窒息メイト +50。定跡は深い型ほど高い（1・3・5・7・10 点）。
- 左メニュー「トロフィー」で、全種類の説明と獲得状況、累計点、1 局の最高点を見られる。
- トロフィーを押すと、見本の局面（`src/data/trophyDemos.ts`）でその手や形を指して確かめられる（参考なので点は入らない）。定跡は、その型に入る直前の局面が開く。
- 判定は盤面からの機械的な形の一致（`src/lib/trophies.ts`）。

## 盤の操作
- 駒をタップ（クリック）→ 行き先をタップ、またはドラッグで指す。
- 選んだ駒をもう一度タップすると、選択を外す。

## GM ゴースト
実際の対局で GM がその局面から指した手を、半透明の駒として盤に表示する（探索モード）。
- 対象：フィッシャー、カスパロフ、カールセン、カパブランカ、モーフィー、タリ、カルポフ、アレヒン（早指し・同時対局などは除外）。
- 右パネルの対局をクリックすると、その一局を「追う」モードになる。GM 側を自分で指し、相手の手は自動再生。「当てるモード」でヒントを隠して次の一手を当てる。
- データ（`public/ghosts/*.json`、約 13MB）は、PGN Mentor（pgnmentor.com）の棋譜集から `sh scripts/fetch-ghosts.sh` で作ったもの。作り直しは 2〜3 分。

## オフライン・データの持ち運び
- `public/sw.js`（サービスワーカー）：画面は通信優先（新しいデプロイを取る）、ビルド済みファイル・エンジン・駒は保存優先、問題や GM データは保存分を即表示して裏で更新。開発サーバーでは登録しない。
- 「今日」の「オフライン用に全部保存」で GM ゴースト（約 15MB）・問題・エンジンをまとめて保存。iPhone は「ホーム画面に追加」で全画面アプリとして開ける（`public/manifest.webmanifest`）。
- 「書き出す」で `dojo.*` の全データを 1 つの JSON に。別の端末で「読み込む」（足す／置き換える）。

## データ
- `src/data/openingNotes.ts`：主要 28 系統の詳しい解説（由来・ポーンの形・白黒の作戦・典型的な戦術と罠・よくあるミス・覚え方）。図鑑と型ドリルに出る。
- `src/data/book.ts`：手書きの定跡集。`w` と `手{割合}` で指される割合（名人戦の概算）を指定。`node scripts/validate-book.ts` で全手順の合法性を検証。
- `src/data/courses.ts`：ドリルのコース定義。`node scripts/check-courses.ts <id>` で展開されるラインを確認。
